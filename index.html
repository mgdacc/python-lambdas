Funciones Lambda

1 / 11

¿Qué es una Lambda?

Una función pequeña, anónima (sin nombre) y de una sola línea.

2 / 11

Sintaxis de una Lambda

Se define con la palabra clave `lambda`, seguida de los argumentos y la expresión.

lambda argumentos: expresion
3 / 11

Lambda vs. Función Normal

Son equivalentes, pero la lambda es más concisa.

# Función normal
def sumar(a, b):
    return a + b

# Función lambda
sumar_lambda = lambda a, b: a + b

print(sumar(2, 3)) # 5
print(sumar_lambda(2, 3)) # 5
4 / 11

¿Por qué usar Lambdas?

Son ideales para funciones cortas y "desechables" que se usan como argumento de otra función.

5 / 11

Uso Común: sort() y sorted()

Para definir una clave de ordenamiento simple y al momento.

# Ordenar por el segundo elemento de cada tupla
puntos = [(1, 5), (3, 2), (5, 8)]
puntos.sort(key=lambda item: item[1])

print(puntos) # [(3, 2), (1, 5), (5, 8)]
6 / 11

Uso Común: map()

Aplica una función a cada elemento de un iterable.

numeros = [1, 2, 3, 4]
# Elevar cada número al cuadrado
cuadrados = list(map(lambda x: x**2, numeros))

print(cuadrados) # [1, 4, 9, 16]
7 / 11

Uso Común: filter()

Filtra elementos de un iterable según una condición.

numeros = [1, 2, 3, 4, 5, 6]
# Obtener solo los números pares
pares = list(filter(lambda x: x % 2 == 0, numeros))

print(pares) # [2, 4, 6]
8 / 11

Limitaciones

Solo pueden contener una única expresión, no múltiples líneas ni declaraciones como `if` o `for`.

# INCORRECTO:
# lambda x: if x > 10: return True

# CORRECTO (usando un ternario):
lambda x: True if x > 10 else False
9 / 11

Llamada Inmediata (IIFE)

Se puede definir y llamar a una lambda en la misma línea (uso poco común).

resultado = (lambda x, y: x + y)(10, 5)

print(resultado) # 15
10 / 11

Conclusión

Las lambdas son una herramienta de conveniencia para escribir código más corto y legible en situaciones específicas.
